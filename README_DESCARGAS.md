# EME GAMES — Descarga de Guardian

## Publicar el juego

1. Genera/exporta Guardian para Windows desde Godot.
2. Comprime la carpeta del juego en un ZIP.
3. En GitHub abre `Emegames/guardian-website` → **Releases** → **Create a new release**.
4. Usa una etiqueta como `v0.1.0`.
5. Sube el archivo con este nombre exacto:

`Guardian-Windows.zip`

6. Publica el Release.

La página ya utiliza este enlace de descarga:

`https://github.com/Emegames/guardian-website/releases/latest/download/Guardian-Windows.zip`

Por eso, cuando publiques una nueva versión manteniendo ese nombre de archivo y marques el Release como el más reciente, el botón seguirá apuntando automáticamente a la versión más reciente.

## Importante

No subas el ZIP del juego como un archivo normal dentro de la carpeta principal del sitio. GitHub Releases está diseñado para distribuir archivos binarios y permite adjuntarlos a una versión.

## Flujo final

Usuario no autenticado → `Crear cuenta para descargar`

Usuario autenticado y correo verificado → `Descargar juego`

Usuario autenticado pero correo no verificado → `Crear cuenta para descargar`
